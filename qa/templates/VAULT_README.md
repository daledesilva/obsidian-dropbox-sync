# Dropbox Sync QA vault (generated)

Integration vault. Regenerated by `bun run qa:generate` / `bun run qa:open` from the `obsidian-dropbox-sync` repo (`release_0.2`).

## First open

1. Enable **Dropbox Sync** (community plugins). `qa:open` installs Hot Reload via `obsidian-launcher watch`.
2. Connect Dropbox (OAuth) if prompted.
3. Sync Now once so `_seeds/` is the remote baseline.
4. Open `_runbooks/INDEX.md`.

## Reset

From the plugin repo:

```bash
bun run qa:reset
```

Reseeds `_runbooks/` and `_seeds/` only. Keeps plugin `data.json` (auth). **Does not wipe Dropbox** — clear the linked remote folder manually after delete/conflict/casing scenarios.

## Agent-assisted runs

Use `/debug-ingest` in Cursor, then enable **Debug logging** in plugin settings and **Send test log**.
