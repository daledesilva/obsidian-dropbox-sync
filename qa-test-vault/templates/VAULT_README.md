From the plugin repo:

```bash
bun run qa:reset
```

Reseeds `_runbooks/` and `_seeds/` only. Keeps plugin `data.json` (auth). **Does not wipe Dropbox** — clear the linked remote folder manually after delete/conflict/casing scenarios.
